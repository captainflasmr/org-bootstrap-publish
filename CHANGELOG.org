#+title: org-bootstrap-publish — Changelog
#+author: James Dyer
#+options: toc:nil

All notable changes to this package.

* 0.4.1 (2026-06-02)

** Fixed

- Custom =org-bootstrap-publish-date-format= now applies to async and published (Cloudflare) builds.  The async child process replays a fixed list of customisations, and =date-format= was missing from it, so deployed sites silently fell back to the default format while interactive builds honoured the custom one.
- Switching site profiles with =org-bootstrap-publish-use-site= no longer risks resetting =org-bootstrap-publish-asset-file= to the wrong directory.  Its default is now captured once at load time, so re-evaluating it during a profile reset stays stable instead of resolving against whatever buffer happens to be current (which could cause =style.css= to be silently skipped during the asset copy).

** Added

- Async builds now warn when =org-bootstrap-publish-shortcodes= contains anonymous lambda handlers.  These cannot be reliably serialised into the child =emacs --batch= process; define handlers as named function symbols in a file listed in =org-bootstrap-publish-async-init-files= and reference them by symbol.

** Changed

- Internal: reordered three =defcustom=/=defvar= forms (=-extra-load-path=, =-async-init-files=, =-sites=) so they precede their first use, silencing byte-compiler free-variable warnings.  No behavioural change.

* 0.4.0 (2026-05-19)

** Changed

- Theme overrides (=org-bootstrap-publish-theme-overrides=) are now emitted against =:root= alone, not every =[data-obp-theme=...]= selector.  The dark and emacs themes in the stylesheet can supply their own values, making the theme toggle produce three visually distinct looks instead of three variations of the same overridden palette.

- Dark and emacs theme blocks in =assets/style.css= no longer set =--obp-sidebar-bg= directly — they inherit it from =:root= and use =color-mix()= to blend theme-specific base colors with the universal sidebar colour, so every theme harmonises with the site's brand colour while keeping its own mood.

* 0.3.0 (2026-05-11)

** Added

- Image viewer overlay for gallery posts: click any image in a masonry grid to open a full-screen overlay with prev/next navigation, keyboard arrows, ESC to close, and body scroll lock.  No external dependencies — implemented in ~50 lines of vanilla JS inlined in the generated HTML.
- Open Graph (`og:`) and Twitter Card meta tags in every page's `<head>`: `og:title`, `og:type`, `og:url`, `og:site_name`, `og:description`, `og:image` (when a post thumbnail is set), and `twitter:card=summary_large_image`.  Post pages get `og:type=article` and the post's own summary/thumbnail; listing pages get `og:type=website` and the site tagline.  Org markup is stripped from summaries automatically.

* 0.2.0 (2026-05-05)

** Added

- =org-bootstrap-publish-preview-limit= defcustom: when set to an integer, preview builds only render the N most-recent posts instead of the full site.  Per-site profiles can set different limits.
- =M-x org-bootstrap-publish-serve-preview=: like =serve= but builds only the =preview-limit= most-recent posts before starting the dev server and rebuild-on-save hook.  Defaults =preview-limit= to 10 when unset.
- =M-x org-bootstrap-publish-serve-site-preview=: switch to a named site profile then preview-serve it.
- Preview-aware save-hook: when =preview-limit= is active, =rebuild-current-post= only parses the current source file and truncates the post list, making incremental rebuilds much faster for multi-source sites.
- =org-bootstrap-publish-serve-browser= defcustom: open the preview URL in a specific browser instead of the default (=browse-url=).
- =org-bootstrap-publish-extra-load-path= defcustom: extra directories added to =load-path= in async/batch builds.  Defaults to auto-detecting the =htmlize= package directory.
- =org-bootstrap-publish-async-init-files= defcustom: Elisp files loaded by the async child before building, so custom shortcode handlers are available without loading user init.

** Fixed

- Syntax highlighting (via =htmlize=) now works in async/batch builds: the child Emacs automatically gets =htmlize='s directory on its =load-path=.
- Custom shortcodes (e.g. =horseprediction=, =crossword=, =foldergallery=) now resolve correctly in async builds when =async-init-files= is set.

* 0.1.0 (2026-05-03)

First numbered release.  Everything below was previously tracked under "Unreleased".

** Added

- Multi-source sites via =org-bootstrap-publish-source-files= (plural).  Merges headings from a list of Org files into one site; save-hook walks the full list for incremental rebuilds.
- Sidebar links with =org-bootstrap-publish-menu-links= (alist of =label . url= pairs).  Entries support =:style cards= or =:style list= to control rendering.  =-menu-tags= is deprecated, translated into the merged list with its original bullet-list style.
- Section landing pages.  Each distinct =EXPORT_HUGO_SECTION= root gets =/<root>/index.html= showing every post in that section, with pagination at =/page/N/=.
- Cross-build HTML cache.  =org-bootstrap-publish-cache-dir= (default: XDG cache) stores rendered =ox-html= output keyed by sha256 of the input.  Warm rebuilds skip unchanged posts; stale entries swept at end of build.  Per-build memoization of cards and Atom entries further reduces render time.
- Gallery posts.  =EXPORT_HUGO_TYPE: gallery= renders a Bootstrap masonry grid from images in =static/<section>/=.
- =EXPORT_FILE_NAME: index= collapses the post URL to =/<section>/=.
- Hugo-shortcode preprocessor for =youtube=, =video=, and =figure=.  User-extensible via =org-bootstrap-publish-shortcodes=.
- Light/dark/emacs theme toggle with =localStorage= persistence and =prefers-color-scheme= detection.  Per-site colour overrides via =org-bootstrap-publish-theme-overrides=.
- Body background image, blur, and opacity (=org-bootstrap-publish-background-image=, =-blur=, =-opacity=).
- Disqus comments per site (=org-bootstrap-publish-disqus-shortname=); skips localhost.
- Layout choice: =org-bootstrap-publish-layout= (=sidebar= / =rightbar= / =topbar=).
- Client-side article search (=index.json= + =search.js=).
- Live-reload for the dev server (polls =reload-token= from localhost only).
- =M-x org-bootstrap-publish-publish= builds async then deploys to Cloudflare Pages via =wrangler pages deploy=.  All output (build + deploy) streams to a single =*obp-publish*= buffer; scrolling up to inspect output is not interrupted by new writes.
- =M-x org-bootstrap-publish-publish-abort= kills the running build or deploy and stops a publish-all chain.
- =org-bootstrap-publish-cloudflare-project= and =org-bootstrap-publish-cloudflare-branch= replace the old git-push deploy variables.  =org-bootstrap-publish-wrangler-executable= (default ="wrangler"=) locates the CLI.
- CI workflow template (=workflows/pages.yml=) deploys to Cloudflare Pages via wrangler.
- =org-bootstrap-publish-site-path= docstring updated — no longer references GitHub Pages.

** Changed

- Feed layout aligned with Hugo: posts at =/<section>/<slug>/=, lowercased slugs, Atom feed at =index.xml= + =feed.xml= alias, =<id>= uses full permalink.
- Per-tag feeds at =/tags/<tag>/index.xml= with =index.html= listing.
- Save-hook rebuilds run in fast mode (skip tag pages/feeds); stylesheet edits also re-copy.
- =--copy-static= mkdirs parent dirs so nested =static/= entries work.
- Suppress =org-confirm-babel-evaluate= during export.
- =--rewrite-static-src= normalises =file://= URLs containing =/static/=.

** Removed

- Git-based deploy (=org-bootstrap-publish-deploy-dir=, =-deploy-remote=, =-deploy-branch=, =-publish-preserve=, =--git=, =--clean-worktree=).  Replaced by Cloudflare Pages deploy via wrangler.
- =.nojekyll= generation (no longer relevant without GitHub Pages).

* 2026-04-23

- Initial release: Bootstrap 5 site generator from Org files.  Post cards, tag pages, atom feed, sidebar, dev server, async builds.
